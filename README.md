# 🐍 Project 2 — Simple Python Program

A beginner-friendly Python project with CI/CD using GitHub Actions.

## What it does
- Demonstrates Python basics: variables, lists, dictionaries, functions, loops
- Includes tests using `pytest`
- Automatically runs tests on every push via GitHub Actions

## How to run locally
```bash
python main.py
```

## How to run tests
```bash
pip install -r requirements.txt
pytest test_main.py -v
```
